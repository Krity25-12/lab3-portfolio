
# Web Development Lab 3

## Lab Title
Responsive Personal Portfolio Website (CSS Advanced)

## Lab Description
The objective of this lab is to design and develop a one-page responsive personal portfolio website using HTML and advanced CSS.

The website uses CSS Flexbox for alignment and navigation, CSS Grid for displaying skills and projects, and media queries to make the layout responsive across desktop, tablet and mobile devices.

It also includes hover effects, CSS transitions, transforms and keyframe animations to improve the website's appearance and user experience.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Animations
- CSS Transitions
- Google Fonts

## Website Sections
1. Header and Navigation
2. Hero Section
3. About Me
4. Skills
5. Projects
6. Contact Form
7. Footer

## Features
- Responsive navigation bar
- Flexbox layout for header and hero section
- CSS Grid for skills and project cards
- Animated profile image
- Hover effects on buttons, links and cards
- Smooth transitions and transformations
- Responsive design for different screen sizes
- Contact form

## Steps to View Responsive Behaviour

1. Open the project folder in Visual Studio Code.
2. Open the index.html file.
3. Right-click and select "Open with Live Server".
4. Open the website in Google Chrome.
5. Press F12 to open Developer Tools.
6. Click the Toggle Device Toolbar icon.
7. Test the website at different screen widths.

## Breakpoints Tested

| Device | Screen Width | Expected Behaviour |
|---|---|---|
| Desktop | 1200px and above | Full navigation, two-column hero and grid layouts |
| Tablet | 768px - 992px | Two-column skills and projects layout |
| Mobile | 375px - 600px | Stacked hero, single-column cards and centered navigation |

### CSS Media Query Breakpoints
- 992px: Tablet layout adjustments
- 600px: Mobile layout adjustments
